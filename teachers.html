For teachers

Brain Break Lab is a small collection of browser activities for short brain breaks: logic, strategy, rhythm, reflex and physics challenges. There are several activities switched on. Pupils don't need an account, nothing is installed, and this site collects no personal data.

Each activity is a separate project hosted on GitHub Pages and shown here in an embedded frame. This site is plain HTML, CSS and JavaScript with no ads, trackers, pop-ups or outside fonts.

Good for quiet time (no timer)

These activities have no timer and no rush, so pupils can take as long as they like over every move.

Some activities also use a few outside services. If these are blocked, the activities still run, but a few extras won't:

  • fonts.googleapis.com and fonts.gstatic.com: optional fonts used inside some activities (they fall back to standard fonts).
  • cdnjs.cloudflare.com: Orb Dash loads its 3D engine from here and won't start without it.
  • Google Firebase (*.firebaseio.com, *.firebasedatabase.app, www.gstatic.com) and PeerJS: the online leaderboards and online matches listed above. Blocking these turns those online features off.
